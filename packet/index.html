Start Here

Start with Need to Know. It's what the brothers said to prioritize: the Classics (with only the last 5 names per role, plus the Aristocrats), the trivia for the active classes (Beta Psi, Beta Chi, Beta Phi, Beta Upsilon), and the Beta Taus and Beta Sigmas.

Tabs: Need to Know · Select Classics (Classics, last 5 names per role, no Moose holder list or brother houses) · All Classics (full role lists + brother houses) · Class Trivia (every class, Chi through Beta Psi) · Everything. Use the dropdown under the tabs to drill one deck. Everything is copied word for word from the packet; pranks aren't included.

Exam format: not in the packet.

Rating: tap the card to flip. Don't know brings it back about 3 cards later, Kinda about 8 later, Know takes it out of this round. A card you know in one tab counts as known everywhere it appears.

EXACT WORDING marks a call-and-response line you have to say word for word. NAMES: NICE TO KNOW marks the long name lists: know what the thing is, the names are a bonus, except bolded names (brothers from Beta Pi or newer), which you should know. In Need to Know and Select Classics the long lists are cut down to Beta Pi and newer only; All Classics keeps the full lists.

Acronyms: DSP = Delta Sigma Pi · BN = Beta Nu · VPPE = Vice President of Pledge Education · PCP = Pledge Class President · NIB = Newly Initiated Brother · COY = Collegian of the Year.

Keys: Space flips, 1 / 2 / 3 rate. Progress saves in this browser.
